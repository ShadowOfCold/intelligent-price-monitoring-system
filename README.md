# Интеллектуальная система мониторинга и анализа цен

## Описание проекта

Интеллектуальная система мониторинга и анализа цен предназначена для автоматизированного сбора, хранения, анализа и прогнозирования цен товаров в интернет-магазинах.

Система позволяет:
- автоматически собирать цены товаров с сайтов интернет-магазинов;
- загружать и обрабатывать документы закупок;
- хранить историю изменения цен;
- выявлять аномалии цен;
- выполнять корреляционный анализ цен между магазинами;
- прогнозировать изменение цен с использованием нейросетевой модели LSTM;
- формировать аналитические Excel и PDF отчёты;
- выполнять автоматический мониторинг по расписанию.

Проект реализован в рамках выпускной квалификационной работы.

---

# Основные возможности системы

## Управление товарами и магазинами

Система предоставляет возможность:
- добавлять, редактировать и удалять товары;
- управлять категориями товаров;
- добавлять, редактировать и удалять интернет-магазины;
- добавлять, редактировать и удалять карточки товаров в магазинах;
- хранить ссылки на страницы товаров.

---

## Сбор цен

Поддерживаются:
- автоматический сбор цен через Selenium;
- загрузка документов закупок;

- обработка ошибок парсинга.

---

Система выполняет:

- прогнозирование цен с использованием LSTM.

---

Поддерживается генерация:
- Excel отчётов;
- PDF отчётов;
- графиков истории цен;
- графиков прогнозирования;
- аналитических таблиц.

---

# Конфигурация окружения

Для работы системы используются файлы:
- `.env` — локальный запуск;
- `.env.docker` — запуск внутри Docker-контейнеров.

Пример `.env`:

```env
POSTGRES_DB=price_monitoring_db
POSTGRES_USER=price_user
POSTGRES_PASSWORD=password
POSTGRES_PORT=5432

DATABASE_URL=postgresql://price_user:password@localhost:5432/price_monitoring_db

API_HOST=127.0.0.1
API_PORT=8000

STREAMLIT_PORT=8501
```

Пример `.env.docker`:

```env
API_HOST=backend
API_PORT=8000
STREAMLIT_PORT=8501

DB_HOST=postgres
DB_PORT=5432
DB_NAME=price_monitoring_db
DB_USER=price_user
DB_PASSWORD=password
DATABASE_URL=postgresql://price_user:password@postgres:5432/price_monitoring_db
```

# Использование системы

## Добавление товаров

1. Добавить товары;
2. Добавить магазины;
3. Добавить карточки товаров в магазинах.

---

## Сбор цен

Система поддерживает:
- сбор цен по одной карточке товара;
- сбор цен по товару;
- массовый сбор цен по всем карточкам товаров.

---

Поддерживается загрузка:
- Excel документов;
- PDF документов.

- просматривать историю цен по товару;
- просматривать историю цен по конкретной карточке товара;
- удалять записи истории цен;
- анализировать графики изменения цен.

---
